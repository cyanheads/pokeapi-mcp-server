# 0.3.0 — 2026-10-30

## Added

- **`pokeapi_team_builder`** takes a lead, an opponent, and an explicit Pokémon/type opponent kind. It returns a pure workflow for the client to discover and verify up to six members including the lead, separating type-chart and base-stat evidence from battle, turn-order, and game-legality claims ([#9](https://github.com/cyanheads/pokeapi-mcp-server/issues/9)).
- **`pokeapi-guide`** covers form-aware identifier chains, search completeness, evolution alternatives, move-version limits, and ability-aware matchup research. It ships through plugin installs, npm, MCPB, and Docker and is served through MCP skills discovery and skill resources.
- **Agent Plugins metadata** adds root `plugin.json` and `mcp.json` alongside the existing client manifests.

## Changed

- **Packaging checks and cleanup** preserve SDK skill runtime modules and published server skills while excluding development files, dependency agent docs, node-gyp intermediates, and build-only package files from MCPB bundles.
- **Framework maintenance** syncs development skills and validation scripts, updates issue-report fields, and adopts advisory classification by installed root version. Bun metadata and Docker images move 1.4.3 → 1.4.4; the dependency minimum release age is one day.
- **Documentation** adds prompt invocation examples, corrects move-summary game-version limits, simplifies setup instructions, and records gated release reviews.
