# 0.3.1 — 2026-11-11

## Added

- **`pokeapi_get_pokemon`** accepts `version_group` to include moves with the requested group's recorded methods and levels. A known group with no entries returns an empty learnset, and an unknown group returns `invalid_version_group`. ([#28](https://github.com/cyanheads/pokeapi-mcp-server/issues/28))
- **Pokémon dossiers** expose National and regional Pokédex numbers and breeding fields on both the tool and resource. ([#31](https://github.com/cyanheads/pokeapi-mcp-server/issues/31))

## Changed

- **`pokeapi_find_pokemon`** includes regional entry numbers and sorts by them before paginating any search with a `pokedex` filter. ([#31](https://github.com/cyanheads/pokeapi-mcp-server/issues/31))
- **Runtime requirement** is Bun 1.4.4 or later when running on Bun.
- **MCPB packaging** strips dependency agent docs at package roots and `SKILL.md` files at any depth. Nested runtime `skills/` directories stay in the bundle.

## Fixed

- **Resource URIs** decode percent-encoded Pokémon and type identifiers once and return a validation error for malformed escapes. ([#23](https://github.com/cyanheads/pokeapi-mcp-server/issues/23))
- **Identifier lookups** accept display spellings such as Poké Ball, Mr. Mime, and Nidoran♀. Invalid identifiers return a lookup error before a record request. ([#27](https://github.com/cyanheads/pokeapi-mcp-server/issues/27))
- **Default learnsets** retain each method's distinct levels from the latest version group and report its name. When chronology metadata is unavailable, the dossier discloses its fallback to PokéAPI source order. ([#28](https://github.com/cyanheads/pokeapi-mcp-server/issues/28))
- **Search filters** accept in-game egg-group names and report the failing filter and its valid PokéAPI names when available. ([#29](https://github.com/cyanheads/pokeapi-mcp-server/issues/29))
- **Flavor text** identifies its source game and explains when the requested version has no English entry. ([#30](https://github.com/cyanheads/pokeapi-mcp-server/issues/30))
