# 0.2.1 — 2026-10-14

## Changed

- **Species resolution** caches verified default-record mappings with the configured TTL and tenant scope, shared by dossiers, resources, and matchups; warm lookups avoid repeated species-name misses ([#24](https://github.com/cyanheads/pokeapi-mcp-server/issues/24)).
- **Default tests** use explicit fetch fixtures and fail unmatched requests, including requests caught by handler error conversion ([#19](https://github.com/cyanheads/pokeapi-mcp-server/issues/19)).
- **Framework tooling** syncs external skills and validation scripts, separates CodeQL language categories, excludes environment files, and prunes musl-only Docker dependencies; Bun metadata and images move 1.4.2 → 1.4.3.

## Fixed

- **`pokeapi_get_type_matchups`** resolves species names to their default variety and returns `resolvedPokemon` and `resolvedFromSpecies` on structured and text surfaces ([#20](https://github.com/cyanheads/pokeapi-mcp-server/issues/20)).
- **`pokeapi_find_pokemon`** joins mixed filters by ID and preserves species rows, retaining suffix-named defaults such as Deoxys without additional requests ([#21](https://github.com/cyanheads/pokeapi-mcp-server/issues/21)).
- **MCP Registry startup** uses `npx` without npm-script arguments and fixes the HTTP transport through `MCP_TRANSPORT_TYPE`.
- **MCPB packaging** excludes first-party tests and fixtures.
