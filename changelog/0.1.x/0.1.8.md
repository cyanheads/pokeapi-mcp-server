# 0.1.8 — 2026-08-23

## Added

- **MCP protocol 2026-07-28 support** ships through MCP SDK v2 while retaining 2025-era client compatibility.
- **Client-visible logging and resource subscriptions** are available through the framework's negotiated protocol capabilities.

## Changed

- **Tool schemas reject unknown root arguments** and advertise `additionalProperties: false`; advertised output schemas accept the framework's structured error envelope.
- **HTTP serving is explicitly stateless** across source, container, registry metadata, and documentation.
- **PokéAPI requests use `fetchWithTimeout` and contextual retries**, so deadlines cover response bodies and retry hints while expected 404s avoid error-level noise.
- **Tool and resource tests use the framework's production storage path** and attach each definition's error contract.
- **Build and packaging support Bun 1.4 and TypeScript 7**, omit optional peers from production images, and exclude `.mcpb` bundles from npm tarballs.
- **Framework scripts, skills, and project guidance** are synchronized with `@cyanheads/mcp-ts-core` 0.12.3; community health files now document contribution, conduct, and private security reporting.

## Fixed

- **Item costs returned as `null` by PokéAPI normalize to `0`**, preserving the server's numeric output contract.
- **Pokémon formatting always renders Legendary and Mythical as Yes or No**, keeping text content in parity with structured output.
- **Dual-type matchup formatting states that offensive relations are unavailable**, instead of silently omitting the structured `null` field.
