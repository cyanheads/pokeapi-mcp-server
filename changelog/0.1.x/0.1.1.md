# 0.1.1 — 2026-06-05

Initial public release of `@cyanheads/pokeapi-mcp-server`. Provides 7 MCP tools and 2 resources over the keyless [PokéAPI v2](https://pokeapi.co/docs/v2):

- **`pokeapi_get_pokemon`** — full Pokémon dossier: base stats, types, abilities, held items, moves by game version, and evolution chain
- **`pokeapi_find_pokemon`** — search Pokémon by type, generation, and minimum stat thresholds; returns ranked matches
- **`pokeapi_get_move`** — move details: type, damage class, power, accuracy, PP, effect text, and machines (TM/HM/TR)
- **`pokeapi_get_ability`** — ability details: effect text, short effect, and the Pokémon that can have it
- **`pokeapi_get_item`** — item details: category, effect text, fling power/effect, and sprite URL
- **`pokeapi_get_nature`** — nature stat modifiers and berry-flavor preferences; lists all 25 when called without an identifier
- **`pokeapi_get_type_matchups`** — offensive and defensive type effectiveness for single- or dual-type combinations

Resources:

- **`pokeapi://pokemon/{identifier}`** — Pokémon dossier by name or dex number (same payload as `pokeapi_get_pokemon` without moves)
- **`pokeapi://type/{typeName}`** — type matchup chart by type name

## Added

- **`pokeapi_get_pokemon`** — flagship tool returning base stats, types, abilities, held items, move list by version group, and full evolution chain via recursive resolution
- **`pokeapi_find_pokemon`** — filtered search across the full Pokédex by type, generation, and stat floor; returns ranked results with summary fields
- **`pokeapi_get_move`** — move details including type, damage class, power, accuracy, PP, English effect text, and TM/HM/TR machine list
- **`pokeapi_get_ability`** — ability effect (long and short English), and the list of Pokémon that carry it
- **`pokeapi_get_item`** — item category, English effect, fling power/effect, and sprite URL
- **`pokeapi_get_nature`** — stat modifier (+10% / −10%) and berry-flavor affinity; list-all mode when called without an identifier
- **`pokeapi_get_type_matchups`** — offensive and defensive effectiveness table for single- or dual-type inputs, with correct dual-type intersection math
- **`pokeapi://pokemon/{identifier}`** — URI-addressable Pokémon dossier resource
- **`pokeapi://type/{typeName}`** — URI-addressable type matchup chart resource
- **`PokeApiService`** — typed fetch layer with in-memory caching (configurable TTL via `POKEAPI_CACHE_TTL_SECONDS`), per-request timeout (`POKEAPI_REQUEST_TIMEOUT_MS`), and retry-on-503 logic
- **`game_version` parameter** on `pokeapi_get_pokemon` — selects move list and flavor text by game version; falls back to first available when no match

## Security

- **`normalizeIdentifier`** — applies `encodeURIComponent` to all path-segment identifiers before they reach the PokéAPI URL, preventing path-traversal via crafted inputs (e.g. `../../etc`)
