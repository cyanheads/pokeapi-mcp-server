# 0.1.7 — 2026-07-11

## Added

- **Bun supply-chain guards** via `bunfig.toml`: `minimumReleaseAge` blocks package versions published under 3 days ago (`@cyanheads/mcp-ts-core` excluded — adopted same-day), and `[install.security] scanner` routes installs through `@socketsecurity/bun-security-scanner` for malware, typosquat, and CVE checks.
- `.github/SECURITY.md` and `.github/FUNDING.yml`.

## Changed

- **`pokeapi_find_pokemon`** — the query-only empty-result notice now renders as a `>` blockquote in `content[]` (`ctx.enrich.notice(...)`) instead of the generic `**notice:**` label. The guidance already reached content-only clients via the enrichment trailer; this only changes how it renders. (#6)
- **`pokeapi_get_type_matchups`** — `composedMultipliers`'s description now documents that the map includes net-neutral 1× cancellation entries for dual-type Pokémon (e.g. Charizard vs Ice: fire resists 0.5×, flying is weak 2× → composes to exactly 1×), not just non-neutral multipliers; the `format()` output gained a matching subtitle. (#5)
- **`docs/design.md`** — corrected two error-contract table entries from `InvalidParams` to `ValidationError` to match the actual handler-declared contracts, and removed a phantom `no_results` reason that `pokeapi_find_pokemon` never declared.
- **Dockerfile** — pinned `oven/bun` base images to `1.3.14` on both build and production stages, added BuildKit cache mounts for the Bun install cache, and the build-stage install now runs with `--ignore-scripts`.
- `package.json` `author` normalized to the full person-object form; LICENSE copyright year updated to 2026.
- Vendored framework skills re-synced to `@cyanheads/mcp-ts-core` 0.10.14 conventions — annotated-tag `--cleanup=whitespace` plus a changelog-link tag footer, `security:` flag scoped to source-only fixes, the flat-object outline-on-overflow pattern, and GHCR verification via `docker manifest inspect`.

## Fixed

- **`pokeapi_find_pokemon`** accepted negative `limit`/`offset` values and returned a misleading success instead of rejecting them. Both fields are now `z.number().int().positive()` / `.int().nonnegative()`, so out-of-range pagination is rejected by the SDK's input-schema validation before the handler runs (`-32602 InvalidParams`) rather than reaching `Array.prototype.slice`. (#7)
- Cleared pre-existing Biome warnings: non-null assertions in `get-type-matchups.tool.ts` and `get-nature.tool.ts` replaced with explicit guards, a redundant `async` keyword removed from eleven `fetch*` methods in `pokeapi-service.ts`, and bracket-notation property access switched to dot notation in `get-nature.tool.ts` and a resource test.
- `scripts/devcheck.ts`'s outdated-dependency check no longer flags packages held back by the new `minimumReleaseAge` guard as unexpected.
